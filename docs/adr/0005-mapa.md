# ADR-0005 — Biblioteca de mapa: Leaflet + OpenStreetMap

**Status:** Aceita, revisada · 2026-09

## Contexto

O diretório precisa de um mapa com dezenas a poucas centenas de pins, em uma única
cidade. Opções discutidas: Leaflet + OSM (gratuito) vs Mapbox/Google Maps (pagos,
com cartão obrigatório).

## Decisão

**React Leaflet**, `leaflet.markercluster` para agrupar pins, componente carregado
com `dynamic(..., { ssr: false })`. Motivos:

- Custo zero e sem cartão de crédito no caminho crítico do lançamento.
- Volume do MVP está muito abaixo de qualquer limite prático de tile gratuito.
- A camada de dados (`lat`/`lng` no banco) é independente da biblioteca: trocar
  de provedor de tile ou migrar para MapLibre/Mapbox depois é reescrever um
  componente, não o modelo.

### Revisão: basemap voltou a ser o tile padrão do OSM

A decisão original usava o basemap **CARTO Positron**
(`basemaps.cartocdn.com/light_all`) por ser mais limpo que o tile padrão do OSM.
Isso deixou de funcionar em produção: a CARTO passa a exigir cadastro de API key
para esse endpoint, e sem ela o tile volta com a marca d'água "API key
required" cobrindo o mapa — foi o que apareceu no site depois do deploy.

O componente (`apps/web/components/map-view.tsx`) volta a usar
`tile.openstreetmap.org`, que continua servindo sem cadastro, sob a [política
de uso da OSM](https://operations.osmfoundation.org/policies/tiles/): não
proíbe o uso, mas pede moderação e desaconselha tráfego alto sustentado sem
contato prévio. Para o volume deste projeto (bairro único, tráfego baixo) isso
é aceitável como base; se o tráfego crescer, é hora de migrar para um provedor
com tier gratuito garantido por cadastro (ver alternativas).

## Consequências

- Atribuição da OSM obrigatória e visível no mapa.
- Visual mais saturado que o Positron — aceito como troca pelo "sem cadastro,
  sem chave, sem risco de quebrar de novo sem aviso".
- Sem tiles vetoriais/3D e com estilização limitada em relação a Mapbox/MapLibre.
- Se o tráfego crescer, ou se quisermos o visual mais clean de volta, migrar
  para um provedor com tier gratuito **garantido por cadastro** (Stadia Maps,
  MapTiler, Thunderforest — free tier real, só e-mail, sem cartão) — ou
  self-host de tiles, que não compensa nesta escala.

## Alternativas

- **CARTO Positron sem conta:** era a decisão original; descartada porque
  passou a exigir API key e quebrou em produção sem aviso prévio no código.
- **CARTO/Stadia/MapTiler com conta cadastrada:** visual melhor, tier gratuito
  real, mas exige guardar uma chave e cadastro prévio — vale a pena revisitar
  quando o design final do mapa importar mais que agora.
- **Mapbox GL / MapLibre + MapTiler:** visual melhor e vetorial; exige conta e chave, e dark patterns de cobrança quando o free tier estoura.
- **Google Maps:** caro, visual genérico, exige billing ativo. Vale só pelo Places autocomplete — que pode ser resolvido no admin com busca no Nominatim (OSM).
